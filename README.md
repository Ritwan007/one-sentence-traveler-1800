A [make.fun](https://make.fun) entry for the competition
[One Sentence for a Traveler from 1800](https://make.fun/competitions/u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb).

`main.py` writes one sentence (157 characters) to `/output/entry.txt`,
explaining the modern internet to a person from 1800 using only words
they would know — a library, a post office, roads, light, ink:

> It is a library with no walls and a post office with no horses, joined by roads of light, where a word you write is read across the sea before the ink dries.

## Run

```sh
python3 main.py   # writes /output/entry.txt
```

No dependencies, no network, no secrets.
